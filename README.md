# AI_Projects 探险手记

D 盘那个 AI 项目文件夹，两年攒了 130 个项目。周末闲着没事翻了一遍，顺手做了个数据画像，记在这里。

- 130 个项目 · 6.7GB · 27,865 个文件
- 2025 + 2026 两年贡献了 115 个 —— 上头是 2025 年下半年开始的
- 项目大小中位数只有 0.55MB —— 一堆小实验，偶尔憋个大的
- 命理玄学浓度意外地高（八字、六爻、印占、算命提示词……）
- 比赛没停过：核聚变、AMD、魔搭、全球攻防，从 2025 一路比到 2026

## 生成方式

- `scan_ai_projects.py` —— 只读扫描目录，收集项目元数据
- `build_dashboard.py` —— 读扫描结果，生成自包含单文件 HTML

想更新就重跑这两个脚本，数字会自动变。
